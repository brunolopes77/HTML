Exemplo 7 - HTML - Listas

Em documentos html podemos usar 3 listas distintas, são elas: lista ordenada, lista não ordena e lista descritiva. Essas listas são representadas pelas tags: <ol>,<ul> e dt/dl/dd. Para todas as listas utilizamos a tag <li>, que representa um item e so pode ser utilizado dentr das listas ordernadas ou não ordenadas.

Lista Ordenada - <ol>

Neste tipo de lista os elementos são distribuídos em ordem, ou seja a ordem importa. Por exemplo:

  1. Planjamento
  2. Design
  3. Desenvolvimento
  4. Testes
  5. Publicação

Lista não ordenada - <ul>

Esse tipo de lista não possui uma ordem específica e eus elementos são representados por bullets. Essa lista é muito utilizada para contrução de menus. Por exemplo:

  • HTML
  • CSS
  • JavaScript
  • Outras tecnologias
