Exemplo 11 - HTML - Formulários

Formulários

Um formulário HTML é criado com a tag form, utilizando elementos como input (texto, email, senha), label (rótulos) e button (botão de envio) para coletar dados do usuário e enviá-los a um servidor via método POST ou GET. É a interface principal para cadastros, login e pesquisas em websites.

O método GET em formulários HTML envia dados anexando-os à URL (como pares nome=valor após um ?), tornando-os visíveis e compartilháveis. É o método padrão, ideal para buscas e navegação, mas não deve ser usado para informações sensíveis (senhas, dados bancários) devido à baixa segurança e limite de tamanho (aprox. 3000 caracteres).
